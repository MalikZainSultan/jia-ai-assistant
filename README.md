# 🤖 Jia AI - Personal Robot & Autonomous Assistant

> **Dedicated Exclusively to Boss Zain Sultan**  
> An intelligent, autonomous personal assistant featuring a futuristic holographic dashboard, hands-free speech recognition, smooth neural voice synthesis, and direct Windows laptop automation.

---

## 🌟 Key Features

- **🌐 Futuristic Holographic Dashboard**:
  - Sci-fi dark cyberpunk glassmorphism UI matching next-gen AI interfaces.
  - Interactive gyroscopic rotating rings and pulsing central AI Sphere with real-time waveform audio visualizer.
  - Quick action modules for Weather, Wallpaper Engine, Browser Launcher, English Learning, and System Apps.

- **🎙️ Hands-Free Speech Recognition**:
  - Built-in Web Speech API voice recognition directly from your laptop microphone.
  - One-click or spacebar microphone activation with live speech transcription.

- **🗣️ Natural Human-like Neural Voice**:
  - Powered by Microsoft Edge Neural TTS (`edge-tts`).
  - Default Voice: `en-US-JennyNeural` (smooth, expressive English).
  - Bilingual Support: `ur-PK-UzmaNeural` for Urdu/Hindi.

- **💻 Direct Windows Laptop Control**:
  - **Browser Automation**: Automatically detects and launches Google Chrome or Microsoft Edge.
  - **Wallpaper Engine**: Downloads and immediately applies high-resolution aesthetic, cyber, space, or nature wallpapers to your Windows desktop.
  - **Desktop Applications**: Launches Notepad, Calculator, VS Code, File Explorer, Settings, and Task Manager on voice command.
  - **File Operations**: Creates and manages folders on the user's Desktop.

- **🎓 English Teacher & Language Mentor**:
  - Teaches vocabulary, pronunciation, grammar structures, and daily inspirational phrases.

- **👑 Unwavering Loyalty to Boss Zain Sultan**:
  - Recognizes and honors Zain Sultan as her sole creator and mentor.

## 🚀 Quick Start

### 1. Requirements
- Windows 10 / 11
- Python 3.12+

### 2. Installation
```powershell
# Clone the repository
git clone https://github.com/MalikZainSultan/jia-ai-assistant.git
cd jia-ai-assistant

# Install dependencies
pip install -r requirements.txt
playwright install chromium
```

### 3. Launching Jia
Simply double-click `jia.bat` or run:
```powershell
python jia.py
```
This automatically launches the futuristic web dashboard at `http://127.0.0.1:5050` in your default browser.
